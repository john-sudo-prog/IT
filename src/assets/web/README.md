# DYCloud AWS SMB专家网站

这是一个基于DYCloud公司官网 [https://www.dycloud.ai/](https://www.dycloud.ai/) 信息定制的AWS SMB能力认证专家网站。

## 功能特点

### 🎨 设计特色
- **现代化UI设计**：采用渐变色彩和卡片式布局
- **完全响应式**：适配桌面、平板和手机设备
- **流畅动画**：悬停效果、滚动动画和过渡效果
- **专业配色**：蓝紫色渐变主题，体现科技感

### 🚀 核心功能
- **智能轮播图**：自动播放，支持手动切换
- **交互式标签页**：SMB服务分级展示
- **平滑滚动导航**：锚点链接平滑跳转
- **AWS SMB认证展示**：突出AWS官方认证能力
- **返回顶部**：便捷的页面导航

### 📱 响应式特性
- **移动端优化**：汉堡菜单和触摸友好设计
- **自适应布局**：CSS Grid和Flexbox布局
- **性能优化**：图片懒加载和防抖处理

## 自定义配置

### 修改颜色主题
在 `styles.css` 中修改以下CSS变量：
```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    --accent-color: #ffd700;
}
```

### 修改内容
- 编辑 `index.html` 中的文本内容
- 替换图片链接为实际图片
- 修改联系信息

### 添加新功能
- 在 `script.js` 中添加新的JavaScript功能
- 在 `styles.css` 中添加新的样式
- 在 `index.html` 中添加新的HTML结构
